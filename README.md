# d-matsui.github.io

Personal website and blog built with Astro.

https://d-matsui.github.io/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/data/blog/` - Blog posts (Markdown)
- `src/pages/` - Pages
- `articles/` - Zenn articles
- `books/` - Zenn books
- `docs/` - Reference docs (not published)
